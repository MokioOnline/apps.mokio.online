What is Blitz?

Blitz is a Minecraft launcher built for people who want instances, mods, and quick play without the clutter. Manage versions, load modpacks, and jump into a world from one clean panel.

What it does

  • Install and switch Minecraft versions in one place
  • Create isolated instances for vanilla, modded, or snapshot play
  • Add mods and modpacks without digging through folders
  • Keep accounts and settings organized per instance
  • Launch straight into the game with one click

How it works

Set up

Sign in and create an instance for the version or modpack you want to play.

Customize

Drop in mods, resource packs, and JVM settings that stay tied to that instance.

Launch

Hit play — Blitz handles the rest so you can get into the world faster.

Features

Instances

Separate profiles for each world style or mod setup.

Mod-friendly

Install and update mods without breaking other instances.

Clean UI

Focus on play, not menus buried three layers deep.

Fast start

Recent instances and one-click launch keep you in the game.
